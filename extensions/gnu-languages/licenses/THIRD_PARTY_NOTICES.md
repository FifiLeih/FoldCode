# Fortran & COBOL extension third-party notices

This package is assembled from Debian 12 Bookworm ARM64 packages. It contains
GCC/GFortran, GnuCOBOL, GNU Binutils, glibc, libxml2 and their dependency
closure. Applicable licenses include GPL-3.0-or-later, LGPL-2.1-or-later,
GPL runtime exceptions and permissive component licenses. Debian copyright
metadata and source package locations govern the exact packaged revisions.
The package preserves those files in `rootfs/usr/share/foldcode-licenses/`;
the extension build must not discard them when manuals and changelogs are
removed.

Corresponding Debian source packages are available from the Debian archive
identified in `SOURCES.json`.
