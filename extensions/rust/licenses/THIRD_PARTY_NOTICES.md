# Rust extension third-party notices

This package contains the official Rust stable compiler, Cargo, rust-analyzer,
rustfmt, Rust standard-library sources, and bare-metal standard libraries for
RP2040 and RP2350 targets. Rust project components are dual-licensed under
Apache-2.0 and MIT unless their source directories state otherwise.

The Linux host runtime also contains Debian ARM64 glibc 2.41, GCC runtime
14.2, zlib 1.3.1 and the Mozilla CA certificate bundle. Their reciprocal and
permissive licenses continue to apply. Source locations are in `SOURCES.json`.
